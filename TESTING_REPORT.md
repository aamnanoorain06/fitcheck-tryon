## Deployment readiness

The local Vite frontend and Express API work together on the configured ports. A static Vite deployment by itself would not provide the Express API. Before a Vercel deployment, choose whether to adapt the Express routes to Vercel Functions or host the API separately, then link/authenticate a Vercel project and configure production environment variables in the Vercel project settings. Do not upload `.env` or expose the service-role/RunPod keys to the browser.
